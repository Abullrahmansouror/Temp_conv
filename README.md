# Temperature Converter

A simple Python command-line utility for converting temperatures between Celsius and Fahrenheit with rounded results.

## Features

- **Bidirectional Conversion:** Convert Celsius to Fahrenheit and vice versa.
- **Precision:** Rounds results to two decimal places for clear readability.
- **Error Handling:** Validates user input and alerts if an invalid unit is selected.

## Requirements

- Python 3.x installed on your machine.

## How to Run

1. Clone or download this repository.
2. Open your terminal or command prompt and navigate to the project directory.
3. Run the Python script:

```bash
python main.py
